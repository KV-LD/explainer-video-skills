# Explainer Video

Turn one message into a paced, narrated 30–90s short. This skill runs the full pipeline — script → storyboard → scene build → narration/caption sync → edit → polish — with a consistent style system throughout. Built for educators and content creators who want a product, how-it-works, onboarding, or concept video from a raw idea.

## When it activates

- "Make an explainer video" or "turn this into a short explainer."
- "Write a script and storyboard for a product video."
- "Produce a how-it-works / onboarding video."
- "Sync narration and captions" or "build a 30–90s animated explainer."

## Example prompts

- "Make a 60s explainer video for our release tool."
- "Write a script and storyboard for an onboarding video, then build it."
- "Add synced narration and burned-in captions to this explainer."

## What's inside

- `SKILL.md` — the script→storyboard→scene-build→narration/caption→edit→polish pipeline, the problem→solution→how→payoff script formula, VO timing math, inlined scene-build techniques, and the cross-scene style system.
