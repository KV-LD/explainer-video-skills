# Diagram Animation

Make structure and data legible by revealing it over time — one idea per beat. This skill builds progressive node/edge reveals, flowing connectors, and animated charts (bars grow, lines draw, numbers count up) for web or video, using SVG, Framer Motion, D3, and Remotion. Built for educators and content creators turning static diagrams into guided reveals.

## When it activates

- "Animate this diagram" or "turn a static diagram into a guided reveal."
- "Build a flowchart that reveals step by step" or "animate an architecture/sequence diagram."
- "Make a chart animate in" — "grow the bars / draw the line / count up the number."
- "Show data flowing along a connector."

## Example prompts

- "Animate this architecture diagram so it reveals node by node, then draws the edges."
- "Make these bars grow and the numbers count up as a chart draws on."
- "Show data flowing along the connectors in this flowchart."

## What's inside

- `SKILL.md` — the progressive-disclosure principle (nodes → edges → labels), a quick-reference table of mechanisms and easings, runnable SVG + GSAP reveals, flowing connectors, chart recipes (bar grow, line draw-on, count-up), and build-tool guidance.
- `references/diagram-and-chart-recipes.md` — fuller runnable code: staged node/edge/label reveals, flowing-dash and traveling-dot connectors, bar/line/count-up charts, sequence-diagram and architecture build patterns, and D3 / Framer Motion / Remotion implementations.
